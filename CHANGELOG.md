# Changelog

## 0.4.0 - Acoustic Realism II
- Independent VST3 plugin ID `PmG4` / `org.personalutilitylab.physicalmodelguitar.realism2`.
- Model-specific nonlinear pick compliance, pick-contact duration and body modal Q.
- Polarization-specific loop loss and conservative displacement exchange.
- Small bounded amplitude-dependent string tension for naturally relaxing pitch.
- New single-note offline WAV renderer for matched-note measurements.
- Reference/synthetic analysis tool for onset, harmonic decay and pitch drift.
- Native tests on 44.1/48/96 kHz passed locally (5/5).
- Windows Actions workflow now builds a true Inno Setup `.exe` installer artifact.
- This release does **not** claim completed measurements against real guitar recordings.
