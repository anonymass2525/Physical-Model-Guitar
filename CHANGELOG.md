# 0.3.0 — Acoustic Realism (new architecture)

- Independent 0.3 plugin identifier, preserving installed 0.2 as a separate instrument.
- Replaced independent 16-note synth voices with six persistent physical guitar strings.
- Two polarized dispersive waveguides per string and velocity-split pick contact excitation.
- One-sided spring-damper fret contact, damped note release and time-varying string delay for pitch bend.
- Shared bridge coupled with a ten-mode resonating body; unplayed strings are sympathetically excited.
- Magnetic pickup spatial aperture, optional second coil, motion induction and passive-load-inspired filtering.
- True stereo body output and 16 exposed physics controls.
- Portable C++17 native DSP tests and four offline demo renders.
- VST3 plugin sources and Windows build workflow prepared; Windows build not yet verified.
