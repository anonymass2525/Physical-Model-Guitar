# Physical Model Guitar 1.2 Research — Unified Acoustic Energy Path

**1.2 の主目的:** 1.1で同時に鳴っていた、エネルギー台帳外の旧ディスプレイスメント波導ドライ音を、統合モードでは完全に音声生成から切り離す。

## 実装済み

- **独立した単一の物理発音経路:** 6弦×2偏波の速度進行波、ピックの有限接触エネルギー、フレット反発と散逸、簡略縦振動、2地点の受動的ブリッジ、弦伝搬損失と再アタック損失を追跡する。
- **観測専用のピックアップとマイク:** 同一物理状態からElectricのコイル速度近似・Acousticの弦近接音とブリッジ速度近似を観測する。観測器は物理モデルへ力を戻さない。
- **v1.1 HYBRID / v1.2 UNIFIED A/B:** `physics12`。JUCE VST3では初期設定OFF（実録音の初回比較で3モデルとも1.1より測定誤差が増えたため。明示的にONで研究・試聴）。OFFは以前のハイブリッド発音方式（1.1）で、既存プロジェクトとは独立したVST3 ID。新しくノートを弾いて比較する。
- **個別アブレーション:** `pick12`, `fret12`, `axial12`, `pickup12`（オフラインレンダラ）。有効・無効で入出力のエネルギーと録音類似度がどう変わるか調査。
- **数値テスト:** 1.2統合経路への旧DSP音声混入なし、接触機構ON/OFFの正しい損失処理、磁気センサの非干渉性、各エネルギー収支、旧版回帰テスト。
- **オンライン研究:** 既存の実ギター録音からアタック・倍音・音高変動の特徴量を比較。独立に外した機構のスコア差で原因候補を絞る。

## 重大な限界（研究版）

統合の対象は **この合成モデルの発音に寄与する内部状態** です。**実ギター全体の物理的エネルギー保存が「完全に証明された」とは言いません。** 接触は低次近似、縦振動はモード、磁気ピックアップの逆作用はゼロ近似、空気への音響放射は観測信号であり、放射による物理散逸は直接同定されていません。摩擦時の熱、ネック、指、電気回路の損失も実測校正未了です。指向性のある実録音を参照し、検証可能な対象を段階的に広げます。

1.1のコードとA/Bスイッチは比較用に維持しています。1.2 ON の音声パスのみ旧DSPを鳴らさない（発音の単一状態化）という意味です。

## 計算と聴感の検証

- CTest、Windows Release、48kHzの同音高・同ベロシティーA/B。
- 音量一致ブラインドA/Bは音色評価用で、FFT特徴量の低さはリアリティの証明ではない。
- 不一致の多いElectricとNylonはアブレーション評価し、モデル全体のデフォルトを強引に最適化しない。
- 絶対SI物性と放射伝達率の識別は、力/速度計測されたブリッジデータや同一ギターの複数テイクで再検証する。
