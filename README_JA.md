# Physical Model Guitar 1.3 Research — Independent Transduction/Radiation

## Research goal
Electric magnetic induction and Nylon far-field acoustic radiation are *distinct observation operators* on the single 1.2 energy-audited 6-string velocity-wave/reciprocal-bridge subsystem. Existing v1.2 default sound is preserved when their flags are off.

## Changes
- `DSP/Observation13.{h,cpp}`: `MagneticPickup13` (five-position normalized magnetic aperture, six strings, two transverse polarizations, displacement-dependent flux-gradient approximation, 2-pole stable RLC-like electrical load, DC removal). A read-only function maps per-string velocity and displacement to EMF; pickup does not apply force to the physical model.
- `NylonRadiation13`: maps two-sided modal bridge velocities into a filtered radiation-pressure proxy plus bounded cavity resonance and direct string radiation. Independent of electromagnetic sensing and free from sample playback.
- `DSP/PowerWaveStrings::sampleTransverseVelocity` permits continuous position readout, interpolating fractional ring indices without modifying wave states or their energy ledger.
- New independent VST3 parameters and GUI controls `1.3 MAGNETIC COIL: A/B` (Electric) and `1.3 NYLON RADIATION: A/B` (Nylon); both default OFF. The new mechanisms are used only with `1.2 UNIFIED / 1.1 HYBRID` ON. Electric and Nylon are isolated from each other, and neither flag affects Steel.
- Standard frequency-aware 44.1 / 48 / 96 kHz offline tests, public guitar reference feature comparison and volume-matched blind listening for ten pairs.

## Important constraints and honesty
This is **NOT** measured/calibrated absolute magnetic flux linkage nor radiation pressure in Pa. Pickup magnet geometry, number of windings, L/R/C, coil/string gap and nylon soundboard velocity maps are approximate and must be individually identified from matched DI/force/accelerometer/microphone recordings. Furthermore, the acoustic observer is deliberately non-loading: real radiation resistance and dissipated acoustic power are not yet reflected back to the bridge. The energy-accounted mechanical subsystem remains passive/invariant to observation, but measured total instrument energy loss, including radiation power, is **NOT fully proven**.

Magnetic nonlinear terms may alias at high input amplitude; a production-quality implementation requires ADAA/oversampling or bandlimited nonlinear readout and calibration. Frequency-dependent body directivity and distance are only rudimentary stereo approximations; they do not model a full 3D acoustic pressure field.

## Verification
- The new observer must not affect stored string/bridge energy, excitation or global ledger.
- With both flags off, v1.2 audio should be bitwise identical to the parent version.
- New Electric only changes electric model and new Nylon only changes nylon model. Steel-control recordings are identical.
- Windows EXE installer is generated by `.github/workflows/windows-v13.yml` (new VST3 product code and new Inno Setup app GUID). Standalone Windows DAW/pluginval and perceptual results are separate.

# Physical Model Guitar 0.6 — Physical Realism III (Research)

Windows VST3物理モデリングギター。従来0.5に横/縦振動連成と摩擦を含むピック接触を追加し、0.5方式と比較できる実験版。

## 変更点
- Pick: bounded, velocity-dependent Stribeck-like stick-slip and tangential spring.
- 1 effective longitudinal oscillatory degree of freedom per string, driven by transverse stretching; bounded tension-dependent pitch and shared bridge excitation.
- 0.5からの物理校正の6弦・4帯域損失・10モード独立調整基盤を保持。
- 新しい製品名 `Physical Model Guitar 0.6` / Plugin Code `PmG6`。0.5と共存。
- `Physics 0.6 / 0.5 Blind A/B` はデフォルトON。OFFで旧計算ルート。`Real Recording Calibration` は独立パラメータで初期OFF。
- 音量一致12ペアのブラインドA/B試聴セット。対応する正解表は別ファイルに保存。
- `Physics06ReferenceBenchmark.py` で外部ギター録音との未使用音高の比較を数値化（録音を配布しない）。

## Windows GitHub Actions
`.github/workflows/windows-v06.yml` はWindows x64でJUCE 9.0.4のVST3＋Standaloneを構築、DSPテスト後、Inno SetupによるEXEインストーラーを作成する。
