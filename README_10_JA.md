# Physical Model Guitar 1.0 Research — Power-Normalized Waveguides

## 設計目標

0.9で実装した「受動的な2地点ブリッジ」に、**物理単位で統一した弦の進行波・反射波**を結合する。
ただし、旧0.9の発音（ピック・フレット・非線形・電気ピックアップ）DSPは音質比較と互換性のために並列で残す。
**今回のエネルギー保存の厳密な検証範囲は `PowerWaveStrings` サブシステムのみ。**

## 数値実装

- 6本の弦 × 2横振動偏波 × 各々1往復の速度波リングバッファ。速度波 `a,b` [m/s]。
- 機械波動インピーダンス `Z = sqrt(T μ)` [N s/m]、例示弦長L=0.65m、張力Tはモデル別の**仮定**。線密度 `μ = T/(2 f_open L)^2` を計算。これらは実物の校正値ではない。
- 2地点の受動的なブリッジ散乱は既存 `TwoPortBridge` を使用。力[N]と速度[m/s]を用い、モード質量は**仮定**したkg値。これにより同一単位でエネルギー収支を計算。
- ナットは理想固定反射（速度反転）。伝搬損失は `0 ≤ gain ≤ 1` で明示的に積算。
- 往復遅延は整数リング＋1次オールパス補間。格納状態とオールパス内部状態を含めて離散エネルギー収支を計算。補間の遅延は低周波近似で、倍音まで厳密な位相遅延ではない。
- 新規ノートの励振は三角変位初期条件を速度波に変換した近似。励振仕事は初期波エネルギーとして計上し、再アタック時の既存波エネルギーをミュート損失へ計上。
- 仕事率・エネルギーは `Z * v^2` と `Δt * Z * v^2` を使用。損失項はブリッジ内部減衰、弦伝搬損失、ノート再アタック時の消音に分離。
- 44.1/48/96kHz、Electric/Steel/Nylonで安定性、受動性、全収支をテストする。
- 旧DSPを1.0 ONでも並列混合しているため、**プラグイン出力全体が物理的にエネルギー保存すると主張しない。**

## 0.9と1.0のA/B

`POWER-WAVE 1.0 / 0.9: A/B` は初期値OFF。OFFでは0.9とビット一致するPCMを確認。
ONでは力・速度の新モデル由来の音を追加。新旧の機械・電気モデルはまだ統合されていない。測定が不十分な現時点で1.0 ONが優れた音だと断定しない。

## 今後の本格的な1.0

- 旧位相/変位ベース弦波導を徐々に全面移行（旧乾音側のエネルギーについても厳密な物理収支を整える）。
- 弦2偏波の連成、ピック・指・フレットを仕事/力で同定し、空間的な集音位置を持つピックアップへ接続。
- 実測弦張力・線密度・弦長、ブリッジの2地点×2方向機械アドミタンス・相互伝達を同定。
- 音量一致のブラインドA/Bと複数テイク実録音を併用し、Steel/Nylon/Electricを別々に評価。

## ビルドとインストール

`cmake -S . -B build -DPMG_BUILD_PLUGIN=OFF && cmake --build build && ctest --test-dir build`。
GitHub Actions `windows-v10.yml` から Windows x64 VST3、Inno Setup EXE を生成。Studio Oneでは旧0.9との併用が可能な独立VST3 ID `Pm10` を設定。
