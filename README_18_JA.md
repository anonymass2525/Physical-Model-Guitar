# Physical Model Guitar 1.8 — Same-Guitar Measurement Lab

## 状態

**実ギターの同時収録は未実施。暫定DSP係数は変更していません。**
この研究キットには実機収録プログラム、物理単位と配線遅延の品質検査、4chの条件付き複素伝達推定、独立保留テイク検証、合成テストが含まれます。

## 測定上の目的

同一ギター・同一固定マイク配置で、**同じADCクロック**を使い、以下を同時に収録します。

| WAV内部チャンネル | 物理量 | 主なセンサー例 | 単位 |
|---|---|---|---|
| 1 | 弦横速度 | LDVのアナログ速度出力 | m/s |
| 2 | ブリッジ速度 | LDVまたは適切に校正して積分した加速度計 | m/s |
| 3 | 近接マイク1 | 校正済みマイク・プリアンプ | Pa |
| 4 | 近接マイク2 | 校正済みマイク・プリアンプ | Pa |

**注意：** 加速度 `m/s²` を速度 `m/s` として誤って保存しないでください。加速度を記録する場合は、帯域制約・ドリフト対策・位相補正を含む校正済みの積分をしてからこの同定ツールに渡します。マイクの音量だけを絶対Paへ変換したことにはなりません。センサーごとに電圧感度、プリアンプゲイン、前段の周波数・位相特性も測定してください。

### MOTU M4で4つのアナログ入力を使う場合の一例

- 入力1・2: マイク（ファンタム電源・ゲインが必要な場合は適切に設定）
- 入力3・4: 外部で必要な信号調整を行った弦速度・ブリッジ速度のライン信号
- 収録マニフェストの `adc_input_map_one_based` を `[3,4,1,2]` にする。これにより出力WAV内では弦、ブリッジ、マイク1、マイク2の順に並ぶ。
- IEPE加速度センサーをインターフェイスへ無調整で直結しないこと。センサー用電源・調整器・適切なゲインが必要。
- 全信号は同一の4入力ADC経由とする。別のUSBマイクと後でWAVを重ねても同期計測と扱わない。

LDVのレーザー安全区分・反射テープの弦振動への影響は機器仕様と測定条件に従い記録してください。特にテープ質量が弦の音響特性を変える可能性があります。

## 測定の流れ

1. 物理的に同一のギターを保持し、弦種、張力（チューニング）、弦高、使用弦・フレット、ピッキング方向・位置、強弱、部屋、温湿度、マイク位置と角度を記録します。
2. センサー感度 `units_per_full_scale` を**実際に校正**。4経路の相対アナログ遅延 `hardware_delay_samples` は実測して補正可能な形で記録します。ADCの電気ループバックだけではLDV内部の遅延は測れません。
3. 同じADCクロックで弦速度、ブリッジ速度、マイク2系統を同時収録。各テイクを独立した4ch FLOAT WAVとして保存します。44.1/48/96kHz等、全テイクのレートを同一に。
4. 6本の弦・複数フレット・指/ピックの位置を変えます。参照速度が十分独立に変化するよう、低振幅のブリッジ励振なども検討します。ただし弦を取り外したり減衰物を挟んだ測定を、通常演奏と同一の機械系だとみなさないでください。
5. 最低8テイクを確保。6以上を学習（`train`）、2以上を未知条件の検証（`holdout`）として**推定前に固定**します。
6. 位相同定では2速度参照の独立性、測定信号のクリッピング、欠落、個体/配置の不整合を拒否します。
7. 未使用テイクの再構成誤差がブリッジ参照のみより5%以上改善したときに限り条件付き伝達関数の「候補」を出力します。
8. **推定値は自動でVST3に採用しません。** 実測器の校正履歴、残差の位相、再現性、音量一致のブラインドA/BとStudio One実機検証を経てからDSP更新を判断します。

### Windowsコマンド例

```
# Python版: python -m pip install -r requirements.txt
python tools/MeasurementStation18.py devices
python tools/MeasurementStation18.py init --manifest .\captured\manifest.json --guitar-id GUITAR_A --geometry-id MIC_RIG_A --interface "MOTU M4" --sample-rate 48000 --input-map 3,4,1,2
python tools/MeasurementStation18.py record --manifest .\captured\manifest.json --seconds 4 --string 3 --fret 5 --excitation pluck --tag trial1
```

録音しただけで自動的に物理量へ校正されるわけではありません。`manifest.json` のセンサー識別子、単位、感度、実測のチャンネル遅延、テイクの `train` / `holdout` を入力し、収録系が実際に校正済みと確認できた場合だけ `is_physical_capture` を `true` にします。

```
python tools/QualifyJointMeasurement18.py --manifest .\captured\manifest.json --out .\captured\measured-candidate.json
```

GitHub Windows EXE版の場合は `PMGMeasurement18.exe` と `PMGQualify18.exe` に読み替えてください。実測音声はプライバシー・権利上、既定ではGitHubへアップロードしません。ローカル保存してください。

## なぜ単音からの「音源完全分離」はできないのか

マイク1・2は弦直接音＋ボディ音＋室内反射を受け取ります。弦速度とブリッジ速度も物理的に結合し、強い周波数相関があります。正則化2入力×2出力の複素伝達推定は、**指定されたセンサー参照と収録配置に条件づけられた伝達経路**を推定するだけです。データ独立性が不十分な場合は拒否します。計測した単一位置から全天球の放射指向性まで決定することはできません。

### 研究の現状と外部資料

- Mark Rau Guitar Measurements: https://rau.mit.edu/projects/GuitarMeasurements/ — LDV/力ハンマーと一部マイクの収録を公開（弦・ブリッジ・マイク2本の4ch同時演奏録音とは限らない）。
- Jasińskiほか (2025): https://doi.org/10.3390/s25216514 — LDV、磁気ピックアップ、マイクの比較。反射テープの弦への影響にも注意。
- Mores 65 guitar measurements: https://zenodo.org/records/4604577 — ブリッジ力・加速度・マイクの実測。**弦の独立速度チャンネルは含まれない**ため、新しい4chモデルをそのまま完全には同定できない。
