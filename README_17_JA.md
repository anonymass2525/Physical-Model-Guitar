# Physical Model Guitar 1.7 Research — 直接音・ボディ音の位相同時同定

## この版で実装したこと

- 1.6の弦・ブリッジの力学を保持したまま、弦の観測信号とブリッジの観測信号を**別の2つの音源参照信号**として扱う。
- 2ブリッジ入力×2近接マイクの初期96タップFIR（1.5の測定由来）と16モードの後期応答（1.6の暫定校正）を合成する。旧1.5出力に含まれる弦の直接音は流用せず、弦速度を独立に読み取って扱う。
- 弦直接音とボディ音の**相対遅延を約±0.9ms**の範囲で3次Lagrange分数遅延により調整する。direct mixも独立調整可能。物理エネルギーには帰還しない。追加の遅延は最大約0.9ms、弦側あるいはボディ側の片方にだけ掛ける。
- `1.7 DIRECT/BODY PHASE: A/B`を初期状態OFF。ONには`1.2 UNIFIED`とClassical Nylonを選択。
- 1.6と同時に使用しても二重に旧1.5の直接音を足さない。ElectricおよびSteelは変更しない。

## 新しい測定・同定ツール

`tools/JointRadiation17.py` は**同一楽器・同一観測マイク位置・同一クロックによる同期4チャンネル録音**が前提。

- ch1: 弦の速度参照（レーザー振動計等）。
- ch2: ブリッジの速度参照（加速度計で測定した場合は校正済みの周波数領域積分・高域／低域のノイズ処理が必要）。
- ch3/ch4: 左右近接マイクの音圧。
- 最低4テイク。3テイク以上を推定に使用、最後1テイクは外部検証に使う。*各テイクは同時録音*し、4ch PCM WAV一つへ結合する。
- マイクの距離・角度、センサー位置、弦の種類、弦高、ピックの種類、弾き方、ゲイン・キャリブレーション、クロック・配線遅延、環境温湿度などのメタデータを保持する。物理的な「弦だけ」「ボディだけ」を完全に作り出すものではない。
- 非独立な参照信号や異なるマイク配置は拒否する。参照信号の識別性が高くても**真の自由音場放射パターンの分離ではない**。マイク位置が固定された**条件付き伝達**の推定である。
- 小サンプルの正則化された2×2クロススペクトル推定。推定された複素周波数応答（Re/Im）、相対ピーク到達時刻、遅い減衰の候補、未使用テイクに対する再構成誤差、参照チャンネルの相関・条件数をJSONに出力する。

```bash
python -m pip install numpy scipy soundfile
python tools/JointRadiation17.py --manifest /path/to/measurement17.json --out result17.json
python tools/TestJointRadiation17.py
```

`tools/measurement17-template.json` が収録マニフェスト例。テンプレート中の識別子は同じ実際の計測条件で置き換える。

## 実測で現在不足している情報

Robert Mores の公開データ https://zenodo.org/records/4604577 は打撃力とブリッジの速度に変換可能な加速度・近接マイク応答を含むが、**弦だけの独立した速度チャンネル**を提供しない。したがって公開データから真の「弦直接放射」と「ボディ放射」をユニークに分離することはできない。1.7に『同一ギターで個別収録完了』という主張はない。

## 審査・出荷のゲート

1. 収録系が同一・同期・校正済みであること。
2. 2つの速度参照が独立同定可能なこと（高相関ビンが多い場合は拒否）。
3. 学習に使わないテイクで2源推定が1源推定より明確に良いこと。
4. 実ギター録音のアタック・倍音・減衰の誤差と聴感上のブラインドA/Bが改善すること。
5. DAW/pluginval負荷・安定性と高サンプルレートを検査すること。

**1.7のデフォルト音色は1.6と同じ。** 今回の放射係数は校正前の研究仮説で、採用済みプリセットではない。
