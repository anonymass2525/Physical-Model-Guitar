# Physical Model Guitar 0.7 — Distributed Fret Mechanics (Experimental)

**目的**：0.6の物理音源を残しながら、発音中の局所的なフレット接触と、同一弦の再ピッキングで消えずに残る微小振動を近似する。

## 音響処理の変更点

- **分散フレット接触**：押弦したフレットよりブリッジ側にある最大5個のフレットを、12平均律から求めた相対座標の接触障害物として表現。各フレットの一方向の接触判定、微小な高さ差、反発と制動、全体の反力上限を設けた。
- **再アタックの残響連続性**：同一弦を再び弾いたとき、旧波動状態をすべてゼロにせず、同じ音高の場合は21%、押弦位置の変更時は5.5%に制限して残す。動作は実験的で、実ギター計測に基づく保存率ではない。
- **v0.6互換A/B**：新しい `Physics 0.7 / 0.6` パラメーターをOFFにすると、v0.6とビット同一の音を生成する。以前の `Physics 0.6 / 0.5` も利用できる。
- **物理パラメーター同定**：前版の弦別接触剛性、周波数帯別減衰、ピックアップ位置補正、10体共鳴モードの校正機構を継承。

## 使用方法

1. `PhysicalModelGuitar-0.7-Windows-x64-Setup.exe` を実行。
2. Studio Oneで `Physical Model Guitar 0.7` を読み込む。
3. GUIの `PHYSICS 0.7 / 0.6: A/B` で切り替える。最初は `REAL RECORDING CALIBRATION` をOFFに固定し、接触物理の差だけを聴く。
4. 弦・フレット・演奏強度により差が小さいことがある。低いFRET CLEARANCE、高いピッキング強度、反復音は接触/再アタックの比較に適する。

## 重要な限界

**音響改善を証明したものではない**。波動ガイドの波形は実寸法の空間変位に厳密に校正されたものではない。フレット反力の上限と移動は力学的不変量に基づく厳密な受動性証明がない。再アタックの残響保持は実測の指によるミュート特性をまだ同定していない。v0.6の単音が好みに合う場合は新方式をOFFにして使える。

## 検証基準

- Linux DSP自動テスト8件、44.1/48/96kHz、各モデル、A/Bの再現性、連続リアタック、有限数値・ピーク上限。
- `Physics 0.7 = OFF` は0.6基準のレンダリング結果SHA-256と一致すること。
- 実録音との特徴量比較と聴感ブラインドA/Bは独立に報告し、改善が成立しないものは不採用。
- Windows GitHub ActionsでVST3+Standalone、EXEインストーラーを生成する。ただしStudio One実機検査・pluginvalは別途必要。
